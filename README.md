# Entre Lagoas — vitrine

Cópia estática da loja WordPress de entrelagoas.com, publicada pelo GitHub Pages.
A loja está em pausa: o carrinho foi escondido e cada produto tem um botão "Encomendar por e-mail".

- `site/` — páginas, fotos e estilos copiados do WordPress
- `ferramentas/limpar.py` — remove rastreadores e código suspeito, esconde carrinho e conta
- `relatorio-limpeza.txt` — o que foi removido na última cópia

O WordPress original (arquivos e banco de dados) está no backup completo da hospedagem,
guardado no Google Drive. Com ele, a loja pode ser reativada em qualquer hospedagem.
